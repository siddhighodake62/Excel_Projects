HAVEN CAFE SHOP DATASET VISUALIZATION

📌 Project Description
Developed an interactive sales dashboard for Haven Cafe to monitor performance, identify trends, and support strategic decision-making. The dashboard consolidates raw transactional data into actionable insights using visual analytics and dynamic filtering.

📊 Key Metrics Tracked
Total Revenue: Daily, weekly, and monthly sales trends
Units Sold: Quantity of items sold across categories
Top-Selling Items: Based on revenue and volume
Category Performance: Beverages, bakery, meals, etc.
Average Order Value: Revenue per transaction
Peak Sales Hours: Time-based performance analysis
Customer Segmentation (if available): Repeat vs. new customers

📈 Visualizations Included
Line Charts: Revenue trends over time
Bar Charts: Top items and category comparisons
Pie Charts: Sales distribution by category
Heatmaps: Hourly and daily sales intensity
Slicers & Filters: Dynamic selection by date, category, item
KPIs: Summary cards for revenue, orders, and growth

🛠️ Tools & Technologies Used
Microsoft Excel: Data cleaning, pivot tables, dashboard layout
Power BI: Advanced visualizations, DAX measures, real-time filtering


🎯 Project Outcome
Enabled Haven Cafe to track sales performance with real-time insights
Identified top-performing products and peak business hours
Improved decision-making for inventory and staffing
